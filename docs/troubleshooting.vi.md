# Xử lý sự cố

Khi hook hoặc lệnh từ chối, verid in một mã như `VERID_BURNT_TDD_NO_FAILING_TEST` kèm bước tiếp theo.
Trang này liệt kê các mã gặp đầu tiên, theo thứ tự luồng bắt đầu nhanh đi qua. Bảng đầy đủ các rule hook
và cách override nằm ở [bảng rule hook](hook-reference.vi.md). Chạy `verid doctor` trước: nó kiểm tra cài đặt,
hook và runner mà không ghi gì.

| Mã                                                             | Thấy khi                                                                                                                                               | Vì sao                                                                                                                   | Làm gì                                                                                                                                          |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `VERID_BURNT_MANIFEST_MISSING`                                 | Lệnh hoặc hook chạy trong thư mục không có `.verid/manifest.yaml`.                                                                                     | Project chưa được thiết lập, hoặc shell đang ở sai thư mục.                                                              | Developer: chạy `verid cook --mode <prep\|recipe\|remix>` ở gốc project. Thêm `--test-cmd`, `--src`, `--tests` nếu verid không nhận ra project. |
| `VERID_BURNT_INIT_IN_AGENT`                                    | Agent chạy `verid cook` hoặc `verid upgrade`.                                                                                                          | Agent không được tự thiết lập lại verid.                                                                                 | Developer: chạy lệnh trong terminal của mình, ngoài Claude Code.                                                                                |
| `VERID_BURNT_RUN_NO_RUNNER`                                    | `verid taste` không tìm thấy test runner.                                                                                                              | verid tự chạy vitest, jest, pytest, Maven, Gradle, .NET, Go, PHPUnit hoặc RSpec; project chưa có runner nào trong số đó. | Thiết lập runner (ví dụ `package.json` có vitest) hoặc đưa `--test-cmd` vào cook, rồi chạy lại `verid taste`.                                   |
| `VERID_BURNT_RUN_NO_BASELINE`                                  | `verid taste` trong project `remix` trước khi chạy `verid stock`.                                                                                      | Phải ghi các test đang fail từ trước.                                                                                    | Developer: chạy `verid stock` trong terminal của mình.                                                                                          |
| `VERID_BURNT_PLAN_NOT_APPROVED`                                | Agent ghi code production khi chưa có module nào được duyệt.                                                                                           | Code production bị khóa tới khi developer order một module.                                                              | Hoàn thiện module trong `.verid/plan.md` (`## Module: <tên>`, mỗi AC một dòng `- AC-1: …`), rồi developer chạy `verid order <module>`.          |
| `VERID_BURNT_MODULE_REQUIRED`                                  | `verid order` khi plan có nhiều module mà không nêu tên.                                                                                               | verid không đoán được module cần duyệt.                                                                                  | Chạy `verid order <module>`.                                                                                                                    |
| `VERID_BURNT_MODULE_OPEN`                                      | `verid order` khi một module khác đang mở.                                                                                                             | Mỗi lúc chỉ một module.                                                                                                  | Xong module đang mở rồi `verid serve`, hoặc sửa hay bỏ section của nó trong `.verid/plan.md`.                                                   |
| `VERID_BURNT_TDD_NO_FAILING_TEST`                              | Agent ghi code production khi vòng đang RAW.                                                                                                           | Không có code production khi chưa có test fail.                                                                          | Viết hoặc sửa test, chạy `verid taste`, kiểm tra nó fail đúng lý do.                                                                            |
| `VERID_BURNT_TDD_TEST_FROZEN`                                  | Agent sửa test khi vòng đang COOKING.                                                                                                                  | Một test đang fail; chỉ code production được làm nó pass.                                                                | Viết code production tối thiểu rồi chạy `verid taste`. Nếu chính test sai, dừng lại và báo developer.                                           |
| `VERID_BURNT_RUN_STALE`                                        | `verid taste` xong sau khi một file đã đổi trong lúc chạy.                                                                                             | Lần chạy có thể không gồm thay đổi mới nhất, nên không phải bằng chứng.                                                  | Chạy lại `verid taste`, không sửa file trong lúc chạy.                                                                                          |
| `VERID_BURNT_ROLE_TESTER_ONLY` / `VERID_BURNT_ROLE_CODER_ONLY` | Coder viết test, hoặc tester viết code production (vai trò Claude Code).                                                                               | Các vai trò tách biệt.                                                                                                   | Gọi tester đã ánh xạ để viết test và coder đã ánh xạ cho code production.                                                                       |
| `VERID_BURNT_TASK_SESSION`                                     | Session AI thứ hai hoặc đã dùng chạm vào code ở big-brain drive.                                                                                       | Mỗi session AI chỉ một task.                                                                                             | Mở session mới cho task mà `verid order` đã chọn.                                                                                               |
| `VERID_BURNT_SERVE_NOT_READY`                                  | `verid serve <module>` bị từ chối. Phần chi tiết nêu chỗ thiếu: AC chưa có test pass, chưa có `verid taste` đạt, hoặc review cũ hơn thay đổi mới nhất. | Module chỉ được serve khi mọi AC có test pass, lần chạy đạt không có thay đổi sau đó, và review còn mới.                 | Bù chỗ thiếu mà chi tiết nêu: chạy `verid taste`, hoặc review lại module, rồi serve.                                                            |
| `VERID_BURNT_SERVE_IN_AGENT`                                   | Agent chạy `verid serve`.                                                                                                                              | Chỉ developer được serve module.                                                                                         | Developer: chạy `verid serve <module>` trong terminal của mình.                                                                                 |
| `VERID_BURNT_HALTED`                                           | Mọi lệnh gọi tool đều bị từ chối.                                                                                                                      | Developer đã chạy `verid halt`.                                                                                          | Dừng và báo công việc đang ở đâu. Developer: chạy `verid resume` khi sẵn sàng.                                                                  |
| `VERID_BURNT_HOOK_PROTECTED`                                   | Agent sửa cài đặt provider, định nghĩa agent hoặc skill, command, plugin hay code verid đã cài.                                                        | Các file này đăng ký hook và vai trò; agent đổi chúng có thể tự gỡ giới hạn.                                             | Developer: tự sửa, ngoài session của agent.                                                                                                     |
