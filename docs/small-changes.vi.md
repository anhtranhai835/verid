# Thay đổi nhỏ

verid không có đường tắt cho thay đổi nhỏ ở `prep` và `recipe`: mọi thay đổi đều đi qua một
module (`order`, build, review, `serve`). Chỉ `remix` là ngắn. Bảng dưới là điều hook ép hiện
nay; mỗi hàng nêu test khẳng định nó.

| Mode và drive          | Tình huống          | Developer chạy                                             | Agent được làm                                                                                      | Test khẳng định                                                                                                                                              |
| ---------------------- | ------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `remix`                | Sửa một dòng        | Không cần                                                  | Viết test đỏ, sửa, chạy `verid taste`. Không cần module.                                            | `tdd.e2e`: "RAW: denies production code, allows tests and other files", "runs the whole loop together with verid taste"                                      |
| `remix`                | Chỉ refactor        | `verid garnish` sau lần chạy xanh                          | Sửa code production khi ở PLATED.                                                                   | `tdd.e2e`: "lets only the developer declare a refactoring session, and only on a passing run"                                                                |
| `remix`                | Một lần ghi bị chặn | `/verid tip <lý do>`, rồi `/verid confirm <mã>`            | Đúng lần ghi đó, một lần.                                                                           | `tdd.e2e`: "lets the developer override the gate once, for that exact write"                                                                                 |
| `prep`/`recipe`, human | Chưa chọn task      | `verid board`, rồi `verid order <module>`, rồi session mới | Không gì cả: code và test bị chặn (`VERID_BURNT_TASK_SESSION`), `/verid tip` không mở được.         | `rules-audit.e2e`: "keeps state, Git internals, MCP configuration and unapproved code protected"; `tdd.e2e`: "will not let /verid tip lift the task session" |
| `prep`/`recipe`, human | Đã order module     | Không thêm                                                 | Chu trình thường: test đỏ trước, rồi code. File nào cũng sửa được; chu trình không gắn file với AC. | `tdd.e2e`: "approves one module of a plan with modules, and opens production code"                                                                           |
| `prep`/`recipe`, auto  | Chưa mở module      | Ký bằng `verid order`                                      | Không được sửa code (`VERID_BURNT_AUTO_NO_MODULE`) tới khi hàng đợi mở module.                      | `auto.e2e`: "locks production code until a module is open, and code and tests while stuck"                                                                   |
| `prep`/`recipe`, auto  | Một lần ghi bị chặn | `/verid tip <lý do>`, rồi `/verid confirm <mã>`            | Đúng lần ghi đó, một lần.                                                                           | `auto.e2e`: "lets the developer tip past an auto lock once"                                                                                                  |

Module đã serve thì code bị khóa lại. Muốn sửa phần đã serve, sửa mục của module đó trong
`.verid/plan.md` rồi order lại.
