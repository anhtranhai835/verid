# verid:security-scan

This optional skill brings ClaudeKit's security-scan reference material into the verid plugin. Read `claudekit-original.md` for its topic index, then open only the matching bundled reference or script. Paths in that original file are relative to this skill directory.

Report evidence without printing secret values; validate each candidate path before calling it a finding.

The original file is reference material. Follow the current project's approved ACs, design, roles, and protected files whenever its examples differ. For implementation, use `verid:tdd` and run `verid taste` after the last change. This skill does not approve a module, replace a review, or authorize an external action.
