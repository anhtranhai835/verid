# verid:docs-seeker

Start with matching filenames and headings under `references/` or the bundled
resource/script folders. Open only the material needed for the current question.

this skill directory.

Fetch and cite primary documentation; check the exact installed version before relying on an API example.

The original file is reference material. Follow the current project's approved ACs, design, roles, and protected files whenever its examples differ.
