# verid:mobile-development

This optional skill brings ClaudeKit's mobile-development reference material into the verid plugin. Read `claudekit-original.md` for its topic index, then open only the matching bundled reference or script. Paths in that original file are relative to this skill directory.

Choose guidance for the actual platform and verify offline, lifecycle, accessibility, and device constraints.

The original file is reference material. Follow the current project's approved ACs, design, roles, and protected files whenever its examples differ. For implementation, use `verid:tdd` and run `verid taste` after the last change. This skill does not approve a module, replace a review, or authorize an external action.
